Diagrama Entidad – Relación (DER)

Cada tabla tiene un id interno autoincremental, de tipo bigint, que solo se usa para relaciones internas y búsquedas más rápidas, y una columna código, de tipo uuid con restricción UNIQUE, que es la que se expone en la API. Las referencias a otros módulos (codigo_pedido, codigo_usuario) se guardan como UUID sin clave foránea, porque cada módulo tiene su propia base de datos.

Relaciones JPA

No hay relaciones @OneToOne ni @ManyToMany. El lado dueño de cada relación es la entidad que tiene la clave foránea (@JoinColumn).

Persistencia con JPA

Usamos JPA como especificación y Hibernate como implementación, sobre H2 en memoria (DEC-11). El código UUID de cada entidad se genera en @PrePersist y las fechas de creación y actualización se completan con @PrePersist y @PreUpdate.
